### drop.io
An open-source project for sharing media, text, or other file types directly across LAN. This is bundled as-is.

## Supported drop types

- Text
- Code with auto-code detection
- URLs and links
- Media (photos, movies, video files, ect) with styled sending/hosting at blazing fast speeds
- Photo (native photo picker)

## Supported devices

- Web at http://server_ip:8000
- native android/iOS support coming soon

## Time Machine
Administrators on the network can view all uploaded files/media sent on the duration of the server. To access these files using the GUI, **you must set a password to make it secure**, otherwise anyone on the network can view all files. When you launch the server.py, you wil see a message:

⌛ Time Machine Password is in: (path to directory)/config.json

Make sure you EDIT AND SET THE PASSORD on first launch by opening the file listed and changing it. The default password is "admin".

## File History

Back up every file on every PC to your server EASILY with File History. Anyone can set up File History EASILY from the drop.io dashboard, and choose files to back up to the server. 


## How it works
A website is hosted at your servers IP, which can be visited by anyone on your WiFi Network with LAN. Anyone who goes to this website is able to send any type of media to anyone who is also on the site!

When you send media, it uploads to your router, which uploads to your server. Then, the recieving device downloads the same file from the server! Because your server never touches the internet - EVER - it is fully encrypted and secure, as well as having blazing fast speeds as you aren't relying on your ISP or the cloud services. You can send a 2gb movie file in as little as a minute over WiFi.
